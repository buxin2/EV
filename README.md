# Buxin EV website

Static website (no build step).

- `index.html` is the main page. Keep this name.
- `css/style.css` holds the styling.
- `js/main.js` and `js/features.js` hold the interactions (menus, vehicle details popup, investor deck popup, contact buttons).
- `images/` holds all photos and the logo.

Upload everything, keeping the folder structure, to a GitHub repository, then turn on GitHub Pages (Settings, Pages, deploy from the main branch, root folder).
